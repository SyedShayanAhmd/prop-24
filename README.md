# Propellair '24 : RC Aircraft Design & Fabrication

### Project Overview
Design, simulation, and fabrication of high-performance RC aircraft for the **IMechE Propellair Competition**. This repository documents the engineering lifecycle of the **"Thunderbolt Falcons"** aircraft, from conceptual sizing to flight testing.

**Achievements:**
* **Best Design Report:** Propellair 2024.

---

### Engineering Specifications
| Feature | Specification |
| :--- | :--- |
| **Airfoil Profile** | NACA 2412 (Optimized for Lift/Drag) |
| **Wing Span** | 55 inches (Tapered Monoplane) |
| **Material** | Balsa Wood (Rib Structure) & Carbon Fiber Spars |
| **Payload Capacity** | 250g (Internal Drop Mechanism) |
| **Analysis Tools** | Ansys Fluent (CFD), XFLR5, SolidWorks |

### Repository Contents
* **/CAD-Models:** Full SolidWorks assembly (`.SLDASM`) and Laser Cutting DXF files.
* **/Simulations:** Ansys Fluent reports (Velocity Streamlines, Pressure Contours).
* **/Reports:** The award-winning Design Reports (PDF).
* **/Fabrication:** Images of the balsa rib assembly and monokote sheeting process.

### Simulation & Analysis
*Designed for stability at 20 m/s wind speeds. Structural integrity validated via FEA on landing gear and wing ribs.*
